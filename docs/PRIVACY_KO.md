# 개인정보와 재배포

공개 소스에는 특정 집의 IP·SSID·MAC·기기 일련번호·위치·계정·토큰·서명 개인키를 넣지 않습니다. 설정 도우미는 설치자의 주소와 장면 ID를 입력받고 로컬 인증정보를 새로 생성합니다. 예제 주소와 테스트 값은 실행용 개인 설정이 아닙니다.

## 공유할 파일

소스 코드, 테스트, 매뉴얼과 공개 예제만 공유합니다. 이 저장소를 처음 받은 상태의 파일 목록을 기준으로 삼습니다.

## 공유하면 안 되는 파일

- `runtime/`: HA OAuth 인증정보, 패널 연결 토큰, 업데이트 키, 로컬 설정과 진단 결과.
- `backups/`: HA 백업, 기기에서 수집한 파일과 펌웨어.
- `hardware/panel-app/build/`: 인증정보가 들어간 생성 코드·키 사본·중간 산출물.
- 생성된 `SmartFactory.apk`, `HomePanel.apk`: 설치자별 주소와 인증값이 내장됩니다.
- USB 메모리 전체 복사본, 패킷 캡처, 스크린샷, 개인 홈 폴더 경로가 포함된 로그.

`.gitignore`는 실수를 줄이기 위한 장치이며 이미 Git에 커밋한 비밀을 지우지는 않습니다. 다른 사람에게 전달하기 전에는 제공하는 개인정보 검사기를 실행하고, 생성 파일을 제외한 새 소스 묶음을 만듭니다. 토큰이 외부로 유출되었다면 해당 HA 인증을 폐기하고 로컬 연결키도 갱신해야 합니다. 기록만 삭제하는 것으로 기존 토큰이 무효화되지는 않습니다.

## 연결 범위

관리용 웹 화면은 Mac의 localhost에서 사용합니다. 단말 화면과 업데이트 수신기는 지정한 집 내부 주소와 토큰을 사용합니다. 구형 단말 호환을 위한 내부 HTTP 연결이 있으므로 이 포트를 인터넷에 직접 공개하지 않습니다. 외부 접속은 별도 VPN 구성을 검토합니다. Mac 방화벽 전체 해제나 공유기 DMZ 설정은 설치 절차에 포함되지 않습니다.

## 진단 파일

고급 메뉴의 수집·백업은 설치자 본인의 기기에서 명시적으로 실행합니다. 결과물에는 기기 정보가 들어갈 수 있으며 공개 GitHub 이슈에 원본을 올리지 않습니다. 문제를 보고할 때는 앱 버전, 단계, 오류의 종류와 개인값을 제거한 짧은 문구만 사용합니다.
