# Home Assistant 준비와 기기 연결

이 문서는 CT1105-SB + Mac mini에서 사용할 Home Assistant(HA)를 준비하는 순서입니다. 기존 HA가 있으면 첫 번째 단계를 건너뜁니다. 계정 암호와 인증 코드는 HA 또는 해당 제조사의 로그인 화면에만 입력합니다.

## 1. Mac mini에서 HA 준비

Home Assistant OS를 가상 머신으로 실행하는 구성을 사용합니다. Docker 설치는 이 프로그램의 필수 조건이 아닙니다. 가상 머신 앱과 HA OS 설치는 자동으로 수행하지 않습니다.

1. [HA 공식 macOS 설치 안내](https://www.home-assistant.io/installation/macos/)에서 Mac의 Intel/Apple Silicon에 맞는 이미지와 가상 머신 구성을 선택합니다. 공식 문서에는 VirtualBox와 UTM 참고 경로가 있습니다.
2. CPU 2개, RAM 2 GB 이상을 배정하고 UEFI 부팅을 사용합니다. 가상 머신 네트워크는 집 네트워크에서 접근 가능한 구성으로 설정합니다.
3. HA OS를 부팅한 뒤 `http://homeassistant.local:8123` 또는 HA 화면에 표시된 실제 주소를 엽니다. 설치 구성에 따라 기본 HTTP 주소로 열릴 수도 있습니다.
4. 본인 관리자 계정을 만들고 실제 집 위치·시간대를 설정합니다. 이 위치가 날씨 통합의 기준이 됩니다.
5. 공유기의 DHCP 예약 기능으로 Mac, HA 가상 머신, CT1105-SB 주소를 고정해 두면 재부팅 후 주소 변경을 줄일 수 있습니다. 세 기기의 IP는 서로 달라야 합니다.

HA 웹 화면이 먼저 정상적으로 열려야 패널 연결을 진행할 수 있습니다. HA OS 업데이트·가상 머신 파일 백업은 HA 공식 안내를 따릅니다.

## 2. SmartThings

HA의 **설정 → 기기 및 서비스 → 통합 구성요소 추가 → SmartThings**에서 본인의 Samsung 계정으로 연결하고, 연결할 위치와 기기 권한을 확인합니다. 연동 방식과 계정/API 이용 조건은 변경될 수 있으므로 [공식 SmartThings 통합 안내](https://www.home-assistant.io/integrations/smartthings/)의 현재 요구사항을 먼저 확인합니다. 패널에는 Samsung 암호를 입력하지 않습니다.

## 3. Tuya Smart / Smart Life

1. 먼저 휴대폰 Tuya Smart 또는 Smart Life 앱에 기기를 등록합니다.
2. HA에서 **통합 구성요소 추가 → Tuya**를 선택합니다.
3. 앱의 **나 → 설정 → 계정 및 보안 → 사용자 코드(User Code)**를 HA 설정 화면에 입력합니다.
4. HA가 표시하는 QR 코드를 해당 앱으로 스캔하고 연결을 승인합니다.
5. 기기나 장면을 추가한 후에는 HA의 Tuya 통합을 다시 불러옵니다.

공식 통합은 앱의 모든 IR 리모컨 기능을 제공하지 않습니다. 에어컨 버튼이 HA에 나타나지 않으면 앱에서 **원터치 실행** 장면을 각각 만듭니다. 방별 기기 탭에 리모컨을 추가하는 것과 원터치 장면 생성은 다릅니다. 예를 들어 원하는 방의 ‘에어컨 켜기’와 ‘에어컨 끄기’를 별도 장면으로 만들고, HA에 나타난 `scene.*` 엔티티 ID를 패널 설정에 지정합니다. IR 전송 성공은 실제 에어컨 상태 확인을 의미하지 않습니다. [공식 Tuya 안내](https://www.home-assistant.io/integrations/tuya/)

## 4. eWeLink / Sonoff 센서 (선택)

eWeLink 앱에서 먼저 센서 값이 보이는지 확인합니다. 필요한 경우 [SonoffLAN 원본 프로젝트](https://github.com/AlexxIT/SonoffLAN)의 설치 방법에 따라 HACS 또는 수동으로 통합을 설치한 뒤 eWeLink 계정으로 연결합니다. SonoffLAN은 별도 커스텀 통합이며 이 저장소에 포함되어 있지 않습니다. 모델·펌웨어에 따라 지원 엔티티가 다르므로 HA에서 CO₂ 센서가 `ppm` 값으로 나타나는지 확인합니다.

## 5. LG ThinQ 세탁기 (선택)

[HA 공식 LG ThinQ 안내](https://www.home-assistant.io/integrations/lg_thinq/)에 따라 본인의 LG 계정으로 ThinQ Connect용 Personal Access Token을 발급하고, HA의 LG ThinQ 통합 설정에 입력합니다. 현재 공식 문서에서 요구하는 권한 범위를 확인합니다. PAT를 저장소나 이슈에 올리지 않습니다.

세탁기 상태·남은 시간·완료 시각은 모델별로 제공 범위가 다릅니다. HA에서 해당 엔티티가 실제 갱신되는 것을 먼저 확인한 뒤 패널 표시와 완료 알림을 시험합니다. 패널 알림만으로 세탁기가 제어되는 것은 아닙니다.

## 6. 방과 대표 센서

HA의 **설정 → 구역/영역**에서 사용할 방을 만들고 기기와 센서를 해당 방에 배정합니다. 방에 여러 온도·습도 센서가 있다면 영역의 대표 온도·습도 엔티티를 지정합니다. 패널은 HA가 제공하는 영역과 엔티티 정보를 사용합니다. CO₂는 단위가 `ppm`인 이산화탄소 센서를 사용합니다.

온도 값이 다르면 패널을 고치기 전에 HA의 엔티티 상태, 단위, 영역 지정과 대표 센서를 비교합니다. 없는 값은 임의의 측정값으로 채우지 않습니다.

## 7. 날씨

HA의 날씨 통합을 추가하고 `weather.*` 엔티티가 실제 집 위치에 맞는지 확인합니다. 기본 패널은 사용 가능한 날씨 엔티티를 선택하므로 여러 날씨 엔티티를 사용한다면 표시되는 이름을 확인합니다. 개인 주소나 위경도는 이 저장소에 들어 있지 않습니다. 24시간 이력과 최근 7일 집계에는 HA Recorder에 실제로 보관된 센서 기록이 필요합니다. 기록이 없으면 과거 값을 만들어 표시하지 않습니다.

## 8. 패널 로그인

Mac에서 패널 서버를 실행한 뒤 `http://localhost:4173`을 열고 **Home Assistant 연결**을 선택합니다. 본인의 HA 로그인 화면에서 인증하면 Mac의 로컬 패널로 돌아옵니다. OAuth 인증정보는 이 설치 폴더의 비공개 `runtime/`에 저장되며 Git에는 포함하지 않습니다.

연결 후 다음을 순서대로 확인합니다.

- 패널에 본인 방 이름과 실제 온습도가 보입니다.
- 사용할 장면의 엔티티 ID를 설정했고 해당 장면이 HA에서도 실행됩니다.
- 기기 연결이 끊기면 오래된 값을 실시간 값으로 표시하지 않습니다.
- CT1105-SB에서도 같은 패널이 열리고 리모컨으로 선택할 수 있습니다.

HA나 제조사 로그인 실패는 해당 HA 통합에서 먼저 해결합니다. 이 프로그램은 계정 인증이나 유료 서비스 가입을 대신하지 않습니다.
